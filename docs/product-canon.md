# VEKTOR Product Canon

Autoridade máxima para decisões de produto. Nenhuma implementação pode contrariar este documento.

## Propósito

A VEKTOR existe para ajudar empresas a evoluírem suas estratégias continuamente.

Não é um gerenciador de tarefas.

Não é um CRM.

Não é um calendário.

É um **Marketing Operating System**.

## Princípios

Toda estratégia deve evoluir.

Execução gera dados.

Dados geram aprendizado.

Aprendizado gera evolução.

Toda decisão de UX deve reduzir complexidade.

Toda funcionalidade deve responder a uma necessidade estratégica.

A IA é um copiloto. Ela analisa, sugere, explica e automatiza tarefas de baixo risco — mas decisões estratégicas permanecem sob aprovação humana. A IA nunca é a protagonista.

## Linguagem

Usuário vê:

- Estratégia
- Execução
- Growth
- Aprendizado
- Evoluir Estratégia

"Estratégia", na linguagem pública, engloba toda a fase de formulação (Diagnóstico, SWOT, ICP, Personas, Posicionamento, Objetivos, Planejamento etc.). Esses elementos continuam existindo metodologicamente, mas aparecem para o usuário como partes da Estratégia — não como módulos independentes.

Internamente o domínio pode continuar usando:

- Objetivo
- Campanha
- Experimento

até futura refatoração.

## Nome do produto

O nome oficial é **Marketing Operating System**. "Growth" não faz parte do nome do produto — é um dos frameworks internos da plataforma (o conjunto de práticas de mensuração, experimentação e recomendação que fecha o ciclo e alimenta a próxima Estratégia).
